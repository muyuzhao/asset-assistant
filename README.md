# 积蓄 · 安卓资产助手

Android 13+ 本地资产与策略助手。只读同步币安账户资产、成交和 BTC 定投记录，提供 AHR999 多源复算参考及分档策略提醒，无需注册或部署服务器。当前版本：0.7.0。

## 构建与安装

准备 JDK 17 或 21、Android SDK Platform 35。项目自带 Gradle 8.11.1 Wrapper，首次构建需要联网下载依赖，也可用 Android Studio 打开项目构建。

在项目目录执行 PowerShell，按实际安装位置修改路径：

```powershell
$env:JAVA_HOME = 'C:\Java\jdk-21'
Set-Content local.properties 'sdk.dir=C:/Android/Sdk'
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

生成的安装包：`app/build/outputs/apk/debug/app-debug.apk`。将其传到手机安装，或通过已连接的 ADB 设备安装：

```powershell
& 'C:\Android\Sdk\platform-tools\adb.exe' install -r .\app\build\outputs\apk\debug\app-debug.apk
```

覆盖安装需保持签名一致；升级前可在 App 中导出备份。当前构建生成 Debug 包。

## 首次使用

1. 打开 App，进入「设置 → 录入只读密钥」。在币安创建系统生成的 HMAC API Key，仅开启所需读取权限，再在手机内填写 API Key 和 Secret Key。
2. 设置同步起始日，执行同步。默认读取最近 180 天；C2C 历史受最近六个月的接口范围限制。
3. 在「总览」查看账户资产和市场参考，在「成交」切换 BTC 定投、VOO、闪兑及 C2C，点击记录查看金额、结算币种、手续费和时间。
4. 按需开启后台同步及系统通知权限；Android 后台调度和省电设置可能影响更新时间。

## 四个页面

| 页面 | 用法 |
| --- | --- |
| 总览 | 查看钱包返回的资产数量、估值、同步时间及 AHR999 复算参考。 |
| 成交 | 按来源浏览订单，查看成交详情与记录状态。 |
| 策略 | 查看固定投入计划，设置分档阈值，开启或管理机会提醒。 |
| 设置 | 管理账户连接、同步范围、后台任务、通知与备份恢复。 |

固定投入按自己的预算在币安执行，App 提供每月和每周的核对提醒；策略设置可调整机会策略阈值。App 不提供手工记账、资金分配或差额补录，实际持仓以钱包读取结果为准。

## 市场参考

AHR999 使用 Coinbase、Kraken、Bitstamp 的公开 BTC/USD 已收盘 UTC 日线独立复算，无需行情 API Key。至少两源日期一致、差异不超过 2%，且处于配置阈值同侧时才确认；缺日、来源分歧或请求失败时保留上次确认值，并显示状态。

计算公式为 `AHR999 = (P / G200) × (P / F)`，其中 `G200` 是 200 日收盘价的几何均值，`F = 10^(5.84 × log10(币龄天数) − 17.01)`，币龄从 2009-01-03 起按 UTC 日期计算。来源、日期与公式可在详情中查看，显示值属于本地复算参考。

## 机会策略提醒

1. 在「策略 → 策略设置」填写四档买入与卖出阈值。默认买入为 0.45 / 0.40 / 0.35 / 0.30，卖出为 1.40 / 1.70 / 2.00 / 2.40，各档比例为 20% / 25% / 25% / 30%。
2. 保存后单独开启机会提醒。开启时先建立基线，等待相邻核对日线从第一买入线上方下穿，不追补此前信号。
3. 买入按本轮开始时确定的预算分档，新存入的钱留给下一轮。卖出按首次卖出前确定的本轮原始机会 BTC 总量分档，最后一档清理全部剩余机会仓；长期定投 BTC 不参与。
4. 提醒详情可选择「我已执行」「跳过这档」或「本轮不参与」。这些操作只管理提醒状态，不会生成交易。进入卖出阶段后停止本轮买入提醒。
5. 本轮清仓后确认结束，等待下一轮下穿；暂停保留进度，恢复不追补暂停期间信号。本轮规则锁定，调整阈值前需先暂停并按界面提示操作。

App 只读查询并发送提醒，不自动下单、不调整币安定投计划，也不读取银行卡余额。系统通知依赖权限，未授权时仍可在 App 内查看提醒。实际行情下穿后的系统通知完整流程仍需在使用中验收。

## 备份与换机

在「设置 → 备份与恢复」导出 JSON 并自行保存，恢复时选择已有备份。备份包含来源记录、市场归档、策略配置及兼容的历史本地事件。导入按事件 ID 合并，冲突时拒绝，并保留导入前副本。

API 凭据由 Android Keystore 加密保存在手机内，不包含在导出备份中。换机或清除 App 数据后，需要重新录入只读密钥。

## 运行测试

设置 `JAVA_HOME` 后运行核心金额模型测试：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1 -TestOnly
```

安装 Debug 包后，可在测试设备上运行隔离测试：

```powershell
& 'C:\Android\Sdk\platform-tools\adb.exe' shell am instrument -w local.asset.assistant/.SmokeTest
```
